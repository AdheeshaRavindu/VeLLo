# Documentation Index

This folder contains supporting documentation for the Hospital Sign-to-Voice Assistant. Use the links below to find design notes, API behavior, verification, and dataset information.

## Live Demo
- Primary demo: [https://vello.adheesha.dev/](https://vello.adheesha.dev/)
- Static gatekeeper page: [https://vello-static.pages.dev/gatekeeper](https://vello-static.pages.dev/gatekeeper)

## Active Sign Set
- `yes`: "Yes."
- `no`: "No."
- `pain`: "I am in pain."
- `water`: "I need water."
- `help`: "Please help me."
- `stop`: "Please stop."
